# CO2 impact on convolutional network model training for autonomous driving through behavioral cloning

This repository contains the code and experimental workflow associated with the research paper titled "CO2 impact on convolutional network model training for autonomous driving through behavioral cloning", published in the Advanced Engineering Informatics Journal.

The project explores the influence of computational cost and carbon emissions associated with training convolutional neural networks for autonomous driving using behavioral cloning. The main objective is to train a model that learns to drive from camera images and steering labels by mimicking human driving behavior observed in simulated environments.

## Project summary

Autonomous driving from visual input can be modeled as a supervised regression problem: given an image of the environment, the model predicts the steering angle required to keep the vehicle on the road. This repository implements a complete pipeline for:

- collecting and preparing simulator-generated driving data,
- applying image preprocessing and data augmentation,
- training convolutional neural networks such as PilotNet and VGG-based models,
- evaluating the model's ability to imitate human driving maneuvers,
- running the trained model in a simulation environment for real-time validation.

The research also analyzes how model architecture, training strategy, and computational cost affect the final driving performance.

## Objective

To develop and document a computer vision-based autonomous driving solution using behavioral cloning, with emphasis on:

- comparing CNN architectures for steering control,
- using data generated by simulation environments,
- preparing datasets with multiple camera viewpoints,
- validating the model in a realistic simulator,
- assessing the relationship between computational cost and performance.

## Methodology

### 1. Training data

The project uses driving data collected in a simulator, typically including images from three cameras (center, left, and right), together with:

- steering angle,
- throttle,
- brake,
- speed.

The frames are used as network inputs, while the associated steering values serve as labels. In many cases, side-camera images are used to increase dataset diversity and improve generalization.

### 2. Preprocessing and data augmentation

Before training, the following operations are applied:

- cropping the upper part of the image,
- conversion to YUV color space,
- Gaussian blur,
- resizing to a normalized input size,
- pixel normalization,
- data augmentation such as horizontal flipping, brightness changes, and geometric variations.

These transformations help the model learn road-relevant features while reducing sensitivity to highly specific scene conditions.

### 3. CNN architectures

The study compares different network architectures for steering regression, especially:

- a PilotNet-like network,
- a VGG-style network.

These architectures extract visual features from the environment and output a continuous steering value approximating the driver’s action.

### 4. Behavioral cloning

The core approach is behavioral cloning:

- the model observes driving scenes,
- learns to mimic the steering action demonstrated in the recorded data,
- is executed in real time to follow a trajectory without explicit handcrafted control rules.

## Workflow

1. Prepare the driving dataset generated by the simulator.
2. Build a dataframe containing image paths and target labels.
3. Split the dataset into training and validation subsets.
4. Apply preprocessing and augmentation.
5. Train the convolutional network.
6. Save the trained model as an `.h5` file.
7. Load the model in the inference script.
8. Run the driving policy in simulation.

```bash

source .venv/bin/activate
pip install -r requirements_TFM.txt
```

### Option 2: conda

```bash
conda create --name tfm_uoc python=3.8
conda activate tfm_uoc
pip install -r requirements_TFM.txt
```

## Training

From the project root, run:

```bash
python Scripts_TFM/TFM_uoc_adbc_PilotNet_VGG.py
```

The script prepares the dataset, trains the network, and stores the resulting model.

## Simulation and inference

The driving scripts load a trained model and control the vehicle using live camera input.

### Version 1

```bash
cd Scripts_TFM
python drive_v1.py
```

### Version 2

```bash
cd Scripts_TFM
python drive_v2.py
```

### Additional variant

```bash
cd Scripts_TFM
python drive4.py
```

These programs receive telemetry from the simulator, apply the same image preprocessing used during training, and predict the steering command required for autonomous driving.
